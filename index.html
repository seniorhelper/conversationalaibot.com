Where the code goes on your platform

One block, pasted once, right before the closing body tag. Here is exactly where that lives on the platform you are already using.

WordPress

Appearance → Theme File Editor → footer.php, just above </body>. Or use a plugin like WPCode and paste it into a footer snippet — safer, because a theme update will not wipe it.

Shopify

Online Store → Themes → Edit code → layout/theme.liquid. Scroll to the bottom and paste above </body>. Works on every theme.

Squarespace

Settings → Advanced → Code Injection → Footer. Paste and save. No theme editing required.

Wix

Settings → Custom Code → Add Custom Code. Set it to load on all pages, placed at "Body — end".

Webflow

Project Settings → Custom Code → Footer Code. Publish after saving or it will not appear on the live site.

Plain HTML

Open the file, paste it near the bottom before </body>, upload. If you have several pages, paste it on each one, or drop it in a shared footer include.

Is the chatbot generator really free?

Yes. No account, no email, no card. The tool runs in your browser and hands you a code snippet you own outright. Nothing is metered, because nothing phones home to us.

Do I need to know how to code?

No. Fill in the form, watch the preview, copy one block of code, paste it before the closing body tag of your site. If you can edit your site's footer, you can install this.

Will it work on WordPress, Wix, Shopify or Squarespace?

Yes. Anywhere you can paste HTML: a WordPress footer or custom HTML block, Shopify theme.liquid, Wix custom code, Squarespace code injection, Webflow custom code, or a plain HTML file.

Rule-based. It answers the questions you wrote answers for and never makes anything up.
